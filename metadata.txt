about=Geocodes address tables (CSV, Excel .xlsx/.xls, OpenDocument .ods, tab-separated) and writes the result as a GeoPackage layer. Addresses are matched against a local SQLite database of official German house coordinates (Hauskoordinaten) with fuzzy search; addresses without a local match can optionally be sent to Nominatim (OpenStreetMap). In GDPR mode no address ever leaves the computer.

  The local database is built inside the plugin: one click downloads the official open data of all 16 German states and imports it — only when there is new data. The plugin handles the states' different services (fixed downloads, feeds, INSPIRE WFS, OGC API Features, per-district ALKIS GeoPackages, job-based download clients). Bavaria is loaded from an OpenStreetMap extract (Geofabrik) because official addresses are not free there. Users can also register their own files (HK-DE text, INSPIRE GML, shapefile or OpenStreetMap extract) per state. The list of sources can be updated online from this repository without a new plugin version.

  Missing postcodes are added automatically from the bundled postcode areas (derived directly from OpenStreetMap, © OpenStreetMap contributors, ODbL).

  Requirements: none beyond QGIS (uses GDAL/OGR from QGIS). Region: Germany only. The user interface and documentation are in German.

  Data licences: official house coordinates mostly dl-de/by-2-0 (Berlin dl-de/zero-2-0, Bremen CC BY 4.0); OpenStreetMap data and the bundled postcode areas ODbL 1.0. Please follow the attribution rules of each source (see the built-in help).
